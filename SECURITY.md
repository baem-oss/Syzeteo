# Security Policy

## Supported version

Security fixes are currently targeted at the latest Syzeteo release.

## Reporting a vulnerability

Do not publish credentials, personal data, database files or exploit details in a public issue. Use the repository owner's private security reporting channel when one is configured on GitHub.

If private security reporting is not available, contact the repository owner privately before disclosing details publicly.

## Data handling

A public Syzeteo repository must never contain productive SQLite databases, WAL/SHM files, backups, real student lists or account credentials.
