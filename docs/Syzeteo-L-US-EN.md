# Syzeteo – User Stories

Status: 27 August 2026

## User Stories

- [x] **US #01 – Change Start Player**  
  As an **Instructor**, I want to replace the automatically selected random start player with another present person before the first question, so that I can adjust the actual start player to the specific game situation when necessary.

- [x] **US #02 – Set Player Selection Mode**  
  As an **Instructor**, I want to specify in the **Instructor Settings** before a game starts whether the regular selection of players from player 2 onward is random or manual, so that I can adapt player selection to the respective teaching and game situation.

- [x] **US #03 – Add Late Arrivals**  
  As an **Instructor**, I want to add students who arrive late to an ongoing round, so that they can still participate in the remainder of the game despite being absent when the game started.

- [x] **US #04 – Central Instructor Settings**  
  As an **Instructor**, I want to view system-wide and game-relevant settings and status information on a central **Instructor Settings** page and, where appropriate, manage them directly, so that I always have a complete overview of the current configuration and can make necessary changes in a targeted manner.

- [x] **US #05 – Sign In to the System**  
  As an **Instructor**, I want to sign in to Syzeteo, so that I can access the game and administration functions intended for me.

- [x] **US #06 – Manage Own Account**  
  As an **Instructor**, I want to change my username and password, so that I can manage my own credentials.

- [x] **US #07 – Manage Courses**  
  As an **Instructor**, I want to create, archive, reactivate, and, when necessary, completely delete courses, so that I can keep the courses used in Syzeteo up to date. When a course is deleted, all data associated with that course is deleted.

- [x] **US #08 – Manage Students**  
  As an **Instructor**, I want to create and edit students in a course and set them as active or inactive, so that the participant population relevant to gameplay can be kept up to date.

- [x] **US #09 – Import Students**  
  As an **Instructor**, I want to import student lists from a CSV file into a course, so that I do not have to enter larger participant groups individually.

- [x] **US #10 – Assign Students to Teams**  
  As an **Instructor**, I want to assign students manually or randomly to Team 1 or Team 2, so that each course has a suitable team structure for gameplay.

- [x] **US #11 – Set Attendance**  
  As an **Instructor**, I want to specify before the game starts which students from the two teams are present, so that only people who are actually present are considered for the designated player roles during the game.

- [x] **US #12 – Manage Learning Units**  
  As an **Instructor**, I want to create, edit, and sort learning units, so that the Question Pool can be organized by subject matter.

- [x] **US #13 – Manage Question Pool**  
  As an **Instructor**, I want to create and edit questions with model answers in the global, cross-course Question Pool, assign them to learning units, and archive them, so that the subject-matter questions available for Syzeteo can be maintained centrally.

- [x] **US #14 – Import and Export Learning Content**  
  As an **Instructor**, I want to export learning units and questions and import them into Syzeteo, so that the subject-matter data can be backed up and transferred between installations.

- [x] **US #15 – Configure Rounds**  
  As an **Instructor**, I want to configure a round using subject-matter questions from the global Question Pool, so that a defined set of questions is available for conducting the round.

- [x] **US #16 – Start Game**  
  As an **Instructor**, I want to start a configured round for a selected course with the students who are present, so that the round can be conducted.

- [x] **US #17 – Conduct and Score Questions**  
  As an **Instructor**, I want to reveal cards during a game, display the associated subject-matter question and model answer, and score the answer, so that the game progression and team points are updated according to the rules.

- [x] **US #18 – Use Team Assist**  
  As an **Instructor**, I want to use the **Team Assist** for the active team and select a present member of that team to answer the current subject-matter question, so that the designated Team Assist can be used during the game.

- [x] **US #19 – Score Challenge Card**  
  As an **Instructor**, I want to score the **Challenge Card** according to the result of the challenge question, so that the resulting team points are awarded correctly.

- [x] **US #20 – Undo Game Step**  
  As an **Instructor**, I want to undo the most recently executed game step, so that an accidental score or player selection can be corrected without restarting the entire game.

- [x] **US #21 – Resume Ongoing Game**  
  As an **Instructor**, I want to reopen a game that has started but is not yet complete and continue from the saved game state, so that a game is not lost when interrupted.

- [x] **US #22 – Use Projector Mode**  
  As an **Instructor**, I want to switch the game view to Projector Mode, so that cards, questions, and the score are displayed large enough for students and without distracting navigation.

- [x] **US #23 – Review Results**  
  As an **Instructor**, I want to see team scores, round results, cumulative results, and the game history of a course in the Results Dashboard after signing in, so that I can review the previous game progression and overall standings at any time.

- [x] **US #24 – Log Played Questions**  
  As an **Instructor**, I want to trace which subject-matter questions were actually played in which round and course and export this log, so that question usage is documented for further teaching and exam planning.

- [x] **US #25 – Check Round Coverage**  
  As an **Instructor**, I want to see which rounds have already been played, are currently in progress, or are still open in which active courses, so that I can monitor the cross-course completion of the planned rounds.
